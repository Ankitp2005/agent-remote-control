# AGENTS.md

Before starting any task in this repo:
1. Read docs/PROJECT.md and docs/ARCHITECTURE.md for constraints, stack
   decisions, and non-goals. Do not violate them without asking the user.
2. Read the docs/phases/PHASE-N-SPEC.md file matching the current task.
3. Build only what that phase's spec describes. Do not implement future
   phases, even if they seem like natural next steps.
4. When a phase spec is split into sub-steps by the user's instruction,
   complete only the requested sub-step, then stop and report what was
   built so the user can verify it before continuing.
